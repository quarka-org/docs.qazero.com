# AI連携（MCP）のプロンプト例

MCP連携では、AIが質問の言葉をQA ZEROのデータ項目に置き換えて集計します。言葉があいまいだと、AIが選ぶ項目や対象のページが変わり、意図と違う答えが返ることがあります。

このページでは、QA ZEROにあるデータと言葉の意味、意図どおりの答えをもらうための聞き方の例をまとめています。MCP連携の概要や接続のしかたは、「[AI連携（MCP）](./ai-mcp.md)」をご覧ください。

## QA ZEROにあるデータと確認できること

QA ZEROには、ページビューや流入元のほか、ページの中での動きまで記録されています。AIには、次のようなことを聞けます。

| データ | 確認できることの例 |
| ----- | ----- |
| ページビュー・訪問 | よく見られているページ、入口になったページ、直帰・離脱の多いページ、ページからページへの移り方 |
| スクロール・読まれ方 | ページのどこまでスクロールされたか（到達率）、熟読されたか、滞在時間 |
| 迷い・不満のサイン | イライラクリック（短い時間の連打）、クリックする場所を探す動き、内容を読み飛ばした動き |
| クリック | ボタンやリンクがクリックされた回数、外部サイトへのリンクのクリック |
| 流入元 | 検索・SNS・広告・メールなど、どこから来た訪問か（utmパラメーターを含む） |
| 端末 | PC・スマホ・タブレットごとの違い |
| Google Search Console | 検索キーワードごとの表示回数・クリック数・掲載順位（[Google Search Console 連携](./google-search-console.md)の設定が必要です） |
| 目標 | 問い合わせなど、設定した目標（コンバージョン）を達成した訪問 |

データ項目の一覧は、[Materials Explorer（データ項目カタログ）](pathname:///ja/tools/materials-explorer/index.html)で確認できます。

## 用語説明

QA ZEROでは、下表のように言葉を定義しています。AIが意図した答えを返さないときは、言葉の意味を伝えると取り違えにくくなります。

| 言葉 | QA ZEROでの意味 |
| ----- | ----- |
| ページビュー | ページが1回表示されること |
| 訪問 | 同じ人のひと続きの閲覧（セッション） |
| 入口 | 訪問の最初に見られたページ |
| 直帰 | 入口のページだけを見て帰った訪問 |
| 離脱 | 訪問の最後に見られたページ |
| 到達率 | ページをどこまでスクロールしたか（0〜100%） |
| 熟読 | ページの中で3秒以上止まった箇所が5か所以上あったページビュー。熟読率は、熟読のページビューの割合 |
| 滞在時間 | そのページを見ていた時間（秒） |
| イライラクリック | 3秒以内に5回以上、連打されたこと |

「熟読率」と似た言葉に「読了率」がありますが、QA ZEROには読了率の決まった項目はありません。「ページの80%以上までスクロールした割合」のように、数え方を決めて伝えてください。熟読率と読了率は数え方が違うため、同じ記事でも、熟読率では上位、読了率では下位になることがあります。

## 聞き方のポイント

質問に次の5つを入れると、答えがぶれにくくなります。

- **対象のページ**
  - 「ブログ記事」ではなく「URLが /blog/ で始まる個別の記事」のように、URLで指定する
  - 記事が並んでいるだけの一覧ページ（カテゴリー別の一覧など）を含めたくないときは、「一覧ページは除いて」と書き添える
- **期間**
  - 期間を必ず入れる（書かないと、AIが直近30日や3か月などを自分で決めてしまう）
  - 「先週」「先月」でも通じるが、範囲をきっちり決めたいときは日付で書く
- **言葉の意味**
  - 「読了率」「離脱」「外部サイト」など、人によって意味が変わる言葉は、どう数えるかを添える
- **数え方**
  - ページビューの数か、訪問の数か
  - 見られた回数が少ないページを除くか（例：ページビューが10以上のページに限る）
  - URLのパラメーターだけが違うものをまとめるか
- **サイトごとのルール**
  - サービス紹介のページや問い合わせ完了のページがどれかは、AIには分からないため、URLで伝える


### AIと認識をそろえる

質問の最後に次の文を添えると、集計を始める前に、AIが使うデータや集計条件を確認できます。

> 集計する前に、どんなデータを使い、期間と対象のページをどう決めるかを、専門用語を使わずに説明してください。判断に迷うところがあれば質問してください。

回答の結果に違和感があるときは、次のように聞くと、使ったデータや数え方を確認できます。

> どのデータを使って、どう数えましたか？専門用語を使わずに教えてください。


## プロンプト例

よくある質問を、伝わりやすい聞き方に書き換えた例です。

<div className="prompt-examples-table">

| あいまいな聞き方 | 伝わりやすい聞き方 |
| ----- | ----- |
| 熟読率が高いブログ記事トップ5を教えて | 2026年9月1日〜30日の間で、URLが /blog/ で始まる個別の記事の中から、熟読率が高いものを5つ教えて。一覧ページ（ブログのトップ・カテゴリー別・タグ別・投稿者別・2ページ目以降）は除いて、ページビューが10以上の記事に限って。URLのパラメーター（?以降）だけが違うものは、同じページとしてまとめて。 |
| スマホとPCで読まれ方は違う？ | 2026年9月1日〜30日の間で、/blog/ で始まる個別の記事（一覧ページ（ブログのトップ・カテゴリー別・タグ別・投稿者別・2ページ目以降）は除く）について、PCとスマホそれぞれの到達率（どこまでスクロールしたか）と滞在時間を、平均と中央値の両方で比べて。タブレットは除いて。 |
| 先週いちばん読まれたページは？ | 2026年10月12日（月）〜18日（日）の間で、ページビューが多いページを5つ教えて。URLのパラメーター（?以降）だけが違うものは、同じページとしてまとめて。管理画面のプレビュー表示は除いて。 |
| 先月と比べて、ブログは読まれている？ | 2026年9月1日〜30日と10月1日〜31日で、/blog/ で始まる個別の記事全体のページビューと、記事を1本以上見た訪問の数を比べて。一覧ページ（ブログのトップ・カテゴリー別・タグ別・投稿者別・2ページ目以降）は除いて。 |
| 直帰率が高いページは？ | 2026年9月1日〜30日の間に、入口になった訪問が10回以上あるページを、直帰率が高い順に5つ教えて。直帰率が同じなら、入口になった回数が多い順に。 |
| 読了率で記事を並べて | 2026年9月1日〜30日の間で、ページの80%以上までスクロールしたページビューの割合を「読了率」として、/blog/ で始まる個別の記事を高い順に並べて。一覧ページ（ブログのトップ・カテゴリー別・タグ別・投稿者別・2ページ目以降）は除いて、ページビューが10以上の記事に限って。URLのパラメーター（?以降）だけが違うものは、同じページとしてまとめて。 |
| クリックして離脱した先はどこ？ | 2026年9月1日〜30日の間で、自社サイト（example.com と、docs.example.com などのサブドメイン）以外へのリンクがクリックされた回数を、リンク先のURLごとに多い順に教えて。SNSのシェアボタンは除いて。 |
| どんなキーワードで来ている？ | Google Search Console のデータで、2026年9月1日〜30日にウェブ検索で表示回数が多かった検索キーワードを10個、クリック数とあわせて教えて。 |
| 問い合わせにつながっているページは？ | 2026年7月1日〜9月30日の間に、問い合わせ完了ページ（/contact/thanks/）まで進んだ訪問について、完了ページより前に見られていたページを、訪問の数が多い順に教えて。問い合わせフォーム（/contact/）と確認画面（/contact/confirm/）は除いて。 |
| ブログを読んだ人は、サービス紹介ページも見ている？ | 2026年9月1日〜30日の間で、/blog/ で始まる個別の記事（一覧ページ（ブログのトップ・カテゴリー別・タグ別・投稿者別・2ページ目以降）は除く）を見た訪問のうち、同じ訪問の中で /service/ で始まるページも見た訪問の割合を教えて。見た順番は問わないで。 |
| 広告から来た人はどこで離脱した？ | 2026年9月1日〜30日の間で、広告のキャンペーン（utm_campaign）が autumn_sale の訪問について、最後に見られたページを、訪問の数が多い順に教えて。URLのパラメーター（?以降）だけが違うものは、同じページとしてまとめて。 |

</div>

※ URLやパラメーターは例です。お使いのサイトに合わせて書き換えてください。
