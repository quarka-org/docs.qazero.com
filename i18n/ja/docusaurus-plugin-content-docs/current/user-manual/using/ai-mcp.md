# AI連携（MCP）

QA ZEROは、MCP（Model Context Protocol、AIと外部のツールやデータをつなぐための共通の仕組み）に対応しています。MCPでAIに接続する（MCP連携）と、AIに話しかけるだけで、QA ZEROに蓄積されたサイトのデータを集計・分析できます。

このページでは、AIでQA ZEROのデータを扱いたい方に向けて、MCP連携の概要と利用時の注意点を説明します。

## MCP連携でできること

- レポート画面を開かずに、AIへの質問で数字を確認できます。
- 条件を変えながら、AIとの対話で分析を進められます。ページビューや流入元のほか、スクロール深度や熟読・探索といった行動データも対象です。
- AIがまとめた結果を、そのまま資料や改善案のたたき台に使えます。

MCP連携は、データの読み取り専用です。AIがQA ZEROの設定やデータを変更することはありません。

AIから扱えるデータ項目は、[Materials Explorer（データ項目カタログ）](pathname:///ja/tools/materials-explorer/index.html)で確認できます。

## 接続のしかた

MCP連携は、**Claude Desktop** と **Claude Code** で利用できます。

接続の手順は、QA ZERO公式サイトの[AI連携（MCP）](https://qazero.com/ai-mcp/)ページにまとめています。ページに掲載している一文をコピーしてClaude Desktop または Claude Code に送ると、Claude が手順を読み、接続まで案内します。

- Claude Code に送るときは、公式サイトの一文にある「Claude Desktop」を「Claude Code」に書き換えてください。
- ChatGPT など、ほかのAIでの接続方法は現在ご案内していません。

接続には次のものが必要です。

- Claude Desktop または Claude Code
- QA ZEROが動いているサイトのURL
- アプリケーションパスワード ※

※ アプリケーションパスワードは、現在QA ZERO事務局で発行しています。ご希望の際は、サポート窓口までお問い合わせください。

## AIへの聞き方

AIは、質問の言葉をQA ZEROのデータ項目に置き換えて集計します。そのため、聞き方によっては意図と違う答えが返ることがあります。

意図どおりの答えをもらうための聞き方や、QA ZEROにあるデータ・言葉の意味は、[AI連携（MCP）のプロンプト例](./ai-mcp-prompts.md)のページにまとめています。

## データは前日分まで

QA ZEROのデータは、毎日夜間に行う集計処理（夜間バッチ）でまとめています。そのため、MCP連携やAPIで取得できるのは**前日分まで**のデータです。当日のデータは、翌朝以降に取得できるようになります。

当日の動きを確認したいときは、管理画面の[リアルタイム](./realtime.md)をご利用ください。

:::note

夜間の集計処理は、毎日深夜2時〜3時ごろ（日本時間）に始まります。データ量が多いサイトでは、処理が明け方までかかることがあります。前日分のデータは、朝6時以降を目安にご利用ください。

:::

## APIを直接使いたい方へ

MCP連携は、QA ZEROのAPI（Application Programming Interface、ほかのシステムからデータを取り出すための窓口）をAIが読み込んで使う仕組みです。APIは、AIを通さずに直接呼び出すこともできます。

自社のシステムやダッシュボードにデータを取り込みたい場合や、独自のツール・エージェントを作りたい場合は、[開発者ガイド](../../developer-manual/introduction.md)をご覧ください。APIの仕様、クエリ言語（QAL）、[MCPサーバーの技術的な設定手順](../../developer-manual/integrations/mcp.md)などを掲載しています。

|   | MCP連携 | API |
| :---: | ----- | ----- |
| 向いている方 | AIに話しかけて、自社サイトのデータを確認・分析したい方 | 自社のシステムやダッシュボードにデータを取り込みたい方、独自のツールを作りたい方 |
| 使い方 | AIに質問するだけ。集計の命令（クエリ）はAIが組み立てます | QA ZEROのクエリ言語（QAL）で集計の命令を書き、APIに送ります |
| 必要な知識 | 専門知識は不要です | プログラミングやAPIの知識が必要です |
| 手順の案内 | 公式サイトの[AI連携（MCP）](https://qazero.com/ai-mcp/) | [開発者ガイド](../../developer-manual/introduction.md) |
